## 📝 INSTALLATION GUIDE

### For End Users

1. **Download** the installer:
   ```
   RĀMAN Studio-2.1.0-Setup.exe (82.7 MB)
   ```

2. **Verify** checksum (optional but recommended):
   ```powershell
   Get-FileHash "RĀMAN Studio-2.1.0-Setup.exe" -Algorithm SHA256
   # Should match: EE0826B25711228C93B7DD37715E6A9C6B8D6D97CE66F0931AF6784529442520
   ```

3. **Run** installer:
   - Double-click the .exe file
   - Windows may show SmartScreen warning (no code signing yet)
   - Click "More info" → "Run anyway"

4. **Install**:
   - Choose installation directory
   - Select "Create desktop shortcut"
   - Click "Install"
   - Wait ~30 seconds

5. **Launch**:
   - Desktop shortcut: "RĀMAN Studio"
   - Or: Start Menu → "RĀMAN Studio"

6. **First Run**:
   - Backend starts automatically
   - Frontend loads in ~2 seconds
   - 30-day trial starts automatically
   - No credit card required

## ⚠️ KNOWN LIMITATIONS

### Build-Related
1. **No Code Signing**: Windows SmartScreen warning
   - Impact: Users see "Unknown publisher"
   - Workaround: Click "More info" → "Run anyway"
   - Fix: Obtain code signing certificate

2. **Default Icon**: Uses Electron default icon
   - Impact: Generic icon in taskbar
   - Workaround: None
   - Fix: Create custom icons

3. **No Auto-Update**: Update infrastructure not deployed
   - Impact: Manual updates required
   - Workaround: Download new version manually
   - Fix: Deploy auto-update server

### Application-Related
1. **License Server**: Not deployed yet
   - Impact: Offline validation only
   - Workaround: Works in trial mode
   - Fix: Deploy license server

2. **NVIDIA NIM**: Requires API key
   - Impact: AI features need configuration
   - Workaround: Works without key (local mode)
   - Fix: None (by design)
